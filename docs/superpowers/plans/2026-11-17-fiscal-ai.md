# Fiscal AI — Plano de Implementação

> **Para agentes:** SUB-SKILL OBRIGATÓRIO: use superpowers:subagent-driven-development (recomendado) ou superpowers:executing-plans para executar este plano tarefa por tarefa. Os passos usam checkbox (`- [ ]`).

**Objetivo:** Sistema web que coleta licitações/contratos da Prefeitura de São Luís/MA, aplica 9 indicadores de risco auditáveis e mostra um ranking público com evidências e explicação gerada por LLM local.

**Arquitetura:** Flask com MVC explícito (`models/`, `controllers/`, `views/`) + camada `services/` (coletores, regras, LLM). Coleta e análise rodam por comandos `flask ...` manuais. Banco MySQL/MariaDB do XAMPP via SQLAlchemy; LLM via Ollama HTTP local.

**Tech Stack:** Python 3.11+, Flask 3, Flask-SQLAlchemy 3.1, PyMySQL, python-dotenv, requests, beautifulsoup4, pdfplumber, scikit-learn, pytest; Bootstrap 5 + Chart.js via CDN; Ollama `qwen2.5:7b`.

**Spec:** `docs/superpowers/specs/2026-11-17-fiscal-ai-design.md`

## Restrições Globais

- Município: **São Luís/MA, IBGE `2111300`**; só órgãos de **esfera municipal** (`orgaoEntidade.esferaId == "M"`).
- Banco: `mysql+pymysql://root:@localhost:3306/fiscal_ai?charset=utf8mb4` (padrão XAMPP, configurável via `DATABASE_URL` no `.env`). Testes usam `sqlite:///:memory:`.
- Ollama: `OLLAMA_URL=http://localhost:11434`, `OLLAMA_MODEL=qwen2.5:7b`.
- Período padrão de coleta: `2025-01-01` até hoje.
- O LLM **nunca** decide se há risco: só extrai dados, responde a regra 4 (CNAE) e redige explicações a partir de evidências já calculadas.
- Todo alerta grava `evidencia` (JSON) com os valores usados e link para a fonte (`link_pncp` ou `url_pdf`).
- Linguagem do painel: "indícios de risco", nunca "fraude"/"corrupção". Aviso fixo em todas as páginas: *"Os alertas indicam indícios de risco calculados automaticamente e não constituem acusação ou prova de irregularidade."*
- Interface em português do Brasil; valores em `R$ 1.234,56`; datas `dd/mm/aaaa`.
- Sem login, sem agendador.

## Foco de Revisão

1. **Recoleta duplicando registros** — rodar `flask coletar` duas vezes no mesmo período não deve duplicar nada (upsert por chave única). Teste na Task 3.
2. **Órgãos estaduais/federais sediados em São Luís** (capital do estado) entrando como "Prefeitura" — devem ser filtrados pela esfera. Teste na Task 3.
3. **Ollama desligado ou resposta não-JSON** — coleta/análise continuam; explicação fica vazia e o painel mostra "explicação indisponível". Testes nas Tasks 6 e 12.
4. **Fornecedor pessoa física (CPF, 11 dígitos) ou CNPJ não encontrado na BrasilAPI** — regras de fornecedor não disparam e não quebram. Testes nas Tasks 4 e 9.
5. **Reanálise** — `flask analisar` duas vezes gera o mesmo score e não acumula alertas. Teste na Task 12.
